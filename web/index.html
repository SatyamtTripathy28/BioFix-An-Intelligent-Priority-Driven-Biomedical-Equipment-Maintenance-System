Maintenance queue

Order: priority, then earlier date, then request number. By default the priority comes from the machine type (Life Support P1, Imaging P2, Diagnostic P3) and can be changed with Edit. A P3 request that is 7 or more days overdue is moved up to P2 ("aged"). Use Done to complete any request, not only the top one. Pin puts a request at the top; the arrows change the order of the pinned requests, and Unpin puts one back. New requests still follow the normal priority order below the pinned ones.
